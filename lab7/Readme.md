## 📘 Topics Covered

### 1. **Introduction to CNNs**
- Motivation and applications of CNNs in image recognition
- Difference between fully connected and convolutional architectures
- Feature extraction and hierarchical representation of data

### 2. **CNN Building Blocks**
- **Convolution Layers:** Filters, stride, padding, feature maps  
- **Pooling Layers:** Max Pooling and Average Pooling  
- **Activation Functions:** ReLU, Leaky ReLU  
- **Flattening & Fully Connected Layers:** Transition to dense layers  
- **Softmax Layer:** For classification outputs

### 3. **Training CNNs**
- Data preprocessing and augmentation (normalization, flips, rotations)
- Training and validation loops
- Optimizers (Adam, SGD)
- Evaluating model performance with accuracy and loss curves

### 4. **Fine-Tuning & Transfer Learning**
- Understanding **feature extraction** vs. **fine-tuning**
- Using **pre-trained models** (e.g., VGG16, ResNet, AlexNet)
- Freezing and unfreezing layers
- Adjusting learning rates for fine-tuning
- Evaluating the benefits of transfer learning on small datasets
