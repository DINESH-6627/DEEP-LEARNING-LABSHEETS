## 🚀 How to Use

### 1️⃣ Use Without Downloading

**View Files Online**  
- Go to the GitHub repository:  
  👉 `[Your Repo URL]`  
- Click on a specific lab folder (e.g., Lab1/).  
- Click on a notebook or Python file to view its contents.  

**Run Code Online**  
- Open the file on GitHub.  
- Click the "Raw" button to copy the code.  
- Paste it into an online Python compiler or Jupyter notebook environment (e.g., [Google Colab](https://colab.research.google.com/)).  

**Edit Files Directly on GitHub (If You Have Write Access)**  
- Open the file on GitHub.  
- Click the pencil (✏️) icon to edit it.  
- Make your changes and click **Commit changes** to save them.
